Dados guardados

O inventário, validades, histórico, plano nutricional e texto reconhecido por OCR são guardados localmente no dispositivo. A aplicação não exige conta e não inclui publicidade ou sistemas de analytics.

Consulta de produtos

Quando um código de barras ainda não existe no catálogo local, o código é consultado no FatSecret e, se necessário, no serviço público Open Food Facts. Fotografias e inventário não são enviados nesse pedido.

Câmara e fotografias

A câmara é usada para códigos de barras e validades. O reconhecimento de texto ocorre no dispositivo. As imagens escolhidas ou capturadas não fazem parte do backup da aplicação.

Backup e eliminação

O utilizador pode exportar um ficheiro JSON com os seus dados. Esse ficheiro fica sob o seu controlo. Desinstalar a aplicação elimina a base de dados local, salvo se existir um backup externo.
